# 🍳 Minha Cozinha - Landing Page

Uma landing page institucional e responsiva para apresentação de receitas culinárias.

## 🚀 Tecnologias Utilizadas
* HTML5 (Estruturação semântica)
* CSS3 (Estilização e Responsividade)

## 📌 Sobre o Projeto
Projeto desenvolvido para simular uma página de apresentação de receitas, contendo seções de ingredientes, modo de preparo e formulário de contato.
